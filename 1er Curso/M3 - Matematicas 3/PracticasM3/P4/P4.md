Aqui usaremos la funcion lp del paquete lpsolve, donde:
direction: si queremos optimizar para conseguir el maximo o el minimo
obj_vec: vector de coeficientes de la funcion objetivo
const_mat: matri de coeficientes numericos de restriccion, una linea por restriccion, una columna por variable
const_dir: vector de strings que indican la direccion de la restriccion(>=,=,<=)
const_rhs: vector de valores numericos a la derecha de las restricciones (<=,=>)
definicion de matrix: matrix(vector of matrix entries by rowss,nrow=number of rows, byrow=TRUE)
$objval: solucion optima para funcion objetivo
$solution: valores optimos para las variables, esta es la solucion optima

ahora hacemos el ejercicio dado en la seccion 3


```r
> library(lpSolve, pos=25)
```


```r
> direction="max"
```



```r
> obj_vec=c(2,1)
```



```r
> const_mat=matrix(c(1,1,1,-2),nrow=2,byrow=TRUE)
```



```r
> const_dir=c("<=","<=")
```



```r
> const_rhs=c(5,3)
```



```r
> sol=lp(direction, obj_vec, const_mat, const_dir, const_rhs)
```



```r
> sol$objval
```

```
[1] 9.333333
```



```r
> sol$solution
```

```
[1] 4.3333333 0.6666667
```

la ultima, sol$solution da los valores de x1 y x2 optimos para la funcion objetivo, que es nuestra solucion
